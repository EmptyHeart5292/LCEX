# ADR-004:PC 网站先行,移动端预留

- 状态:已确认(2026-08-30)

## 背景

产品需要覆盖 PC 与移动端,但资源有限,需确定先后。

## 决策

1. **PC 网站(apps/web)先行**,Phase 1 开始开发;
2. **移动端 APP(apps/mobile)仅保留目录与说明**,不放置代码;
3. 后端能力全部通过 `packages/api-spec` 契约暴露(REST OpenAPI + WS 协议),保证移动端后续接入零后端改动;
4. 移动端技术选型倾向 React Native(与 web 共享 TypeScript 类型与业务逻辑),最终决策推迟到启动移动端时。

## 后果

- 移动端延后不影响后端设计;契约先行是本决策的配套纪律。
