# ADR-006:自建内部做市,拆分指数价与做市两个服务

- 状态:已确认(2026-08-30)

## 背景

新交易所盘口空,无自然流动性,价格无法对齐大所。需要对齐 Binance / OKX / Bybit / MEXC / Bitget 的价格。

## 决策

拆成两个服务:

1. **price-index**:订阅五所公共行情,加权计算指数价,剔除异常源。用途:做市锚、行情薄盘回退展示、风控参考价、二期合约标记价格。
2. **market-maker**:以指数价为锚在本所盘口双边挂单,cancel/replace 刷新;库存通过外部交易所私有 API 对冲保持中性。

硬性约束:

- 做市订单走 order → matching → clearing 正常链路,不绕过风控与账本;
- 全局 kill switch、单交易对暂停开关必须存在;
- 与指数价最大偏移限制、最大挂单名义额限制,对冲通道故障自动停止报价。

## 后果

- 对冲手续费与滑点计入运营成本;
- 做市参数需纳入风控监管与审计;
- 公开灰度前 market-maker 必须稳定运行(见 docs/roadmap.md)。
