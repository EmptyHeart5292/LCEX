# ADR-001:撮合引擎使用 Rust

- 状态:已确认(2026-08-30)

## 背景

撮合引擎要求:确定性(可从事件日志重放恢复)、低且稳定的延迟(无 GC 停顿)、高吞吐。候选:Rust / C++ / Java(LMAX 模式)。

## 决策

使用 Rust,代码位于 `matching/`(Cargo workspace)。每个交易对一个单线程引擎实例,订单簿全内存,无跨线程共享锁;输入输出全部经 Kafka,事件溯源。

## 后果

- 收益:无 GC、内存安全,确定性重放天然实现;
- 代价:开发速度略慢,需要熟悉 Rust 的开发资源;
- 备选方案:全 Go(Go 单交易对 10 万 TPS 可满足 MVP),若 Rust 资源不足可回退。
