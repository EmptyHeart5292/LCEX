# ADR-005:MVP 不接入 KYC,合规能力按主流交易所通行方式预留

- 状态:已确认(2026-08-30)

## 背景

牌照与 KYC 供应商接入周期长、成本高;MVP 先验证交易闭环。合规要求因司法辖区差异极大,需专业法律顾问,此处只做系统层预留。

## 决策

1. MVP 不接入 KYC 供应商;
2. 数据模型预留:`users.kyc_level`(默认 0)与审核流水表结构,后续接入 Sumsub/Jumio 时零迁移;
3. 无 KYC 用户提现限额从紧(具体数值运营配置);
4. 制裁地址筛查(Chainalysis / TRM)在 risk 中预留接口,Travel Rule 预留上报接口,按主流交易所通行做法设计;
5. 接入时点取决于牌照进展,不在当前路线图关键路径上。

## 后果

- 后续接 KYC 时不改核心账本与交易链路;
- 面向公众运营前必须完成辖区合规评估(法律顾问),技术预留不等于合规豁免。
