# ADR-002:钱包采用托管方案(Fireblocks / Cobo)

- 状态:已确认(2026-08-30)

## 背景

私钥安全是 CEX 最大的单点风险,自建冷热钱包与签名体系需要专职安全团队与长期审计。MVP 阶段自建的收益不足以覆盖风险。

## 决策

MVP 使用托管 MPC 方案(Fireblocks 或 Cobo)。`wallet` 服务内部定义 **Provider 接口**抽象托管商(地址派生、签名广播、回调/扫链、归集),供应商差异不外泄。

## 后果

- 收益:私钥安全由专业供应商承担,上线周期缩短;
- 代价:托管费用与供应商依赖;
- 缓解:通过 Provider 接口控制迁移成本;自建冷热钱包体系延后到有专职安全团队时评估。
