# clearing

清算服务:成交事件 → 账本变动。整个交易所资金正确性的落点。

## 职责

- 消费 matching 的成交事件,为买卖双方生成复式分录:成交划转、冻结释放、手续费;
- 费率计算(maker/taker,VIP 等级预留);
- 幂等:按 trade_id 去重,容忍 Kafka 重复投递;
- 输出余额变更事件(供 WS 推送)与清算流水(供对账)。

## 不变式(见 docs/architecture.md §5)

- 任何资金变动必须落在 journal / ledger_entry,借贷必平;余额是流水的推导结果,禁止直接改余额;
- 每日重放流水校验各账户余额,不平即告警并冻结相关功能。
